# 零新增费用补验后：论文可行性与期刊建议

核验日期：2026-10-01。本次没有新增付费 API、没有充值、没有启动 GPU；补验只使用已有缓存、本地 CPU 和公开文献。本报告是写作依据与投稿评估，不是已经写完或已经投稿的论文。

## 结论

**可以据此写一篇完整的实证研究论文，无须为了形成当前故事继续购买 API 或 GPU。** 合适的主线是：在共同数据与标签预算下，比较 Jev 类型化概率特征、Qwen token 概率、通用 LLM 自报概率、字符串特征和 Ditto，解释不同系统适用的任务与预算范围。

实验覆盖与证据链已足以支撑这个范围。它仍是一项 Jev 案例研究：不能外推到全部商业类型化模型，不能声称类型化输出本身带来准确率优势，也不能宣称全局最优或错误检测 SOTA。是否被期刊接受还取决于论证的新意和稿件质量；实验做得多不等于创新性自动成立。

建议题目：**Probability Interfaces for Low-Label Entity Matching: A Controlled Study of Jev, Token Probabilities, and Generative LLMs**。

## 能够组成论文的结果链

1. **商品匹配的低标注优势可以保留。** b200 的 Jev 拆题 F1 在 WA/AG/AB 为 87.612/67.296/91.896，对 Qwen 拆题分别高 7.106/11.643/9.892 点，原主分析描述性 95% 区间均不含零。新作者库字符串 LR 的对应差值为 17.625/12.150/47.139 点，区间也均为正。b50 对新字符串基线的商品优势同样保留。
2. **DBLP–ACM 提供反例，决定论证边界。** b200 Jev 与 Qwen 拆题只差 0.029 点；对新作者库字符串 LR 差 0.715 点，区间包含零。b50 Jev 比该 LR 基线的点估计还低 0.569 点。不能写“所有任务、所有预算都更好”。
3. **拆题收益并非 Jev 独有。** Jev 的 b200 D−H 在三个数据集点估计为正，但相对 Qwen 的四个拆题交互都为负；这是对原假设的有用修正。系统最终质量与拆题相对收益必须分开。
4. **强 LLM 竞争者必须保留。** 同 500 对、同 b200 三种子的拆题比较中，Luna 在 WA/DA/AB 的点估计高于 Jev，AG 较低；零样本 Luna 同样很强。完整论文不能只突出与低预算 Ditto 和字符串分类器的差距。
5. **概率需要实测，格式约束不能替代校准。** 温度、ECE/Brier/NLL、选择性风险和数值探针已有结果。历史诊断出现答案与概率字段冲突，说明评价必须固定读出语义；本轮分别保存两种读法，没有以测试表现择优替换主协议。
6. **部署价值是有条件的。** 同路由 48 个设计对的测量显示 Jev 推理单价和延迟较低。这支持测量范围内的工程取舍，不是完整业务总成本、性能等价服务或 GPU 租赁发票比较。

上述数据与区间见[补验结果与限制](补验结果与限制.md)及原[中文完整论证](../../jevwrangle/reports/final_delivery_20261001/中文完整论证与交付说明.md)。新比较为审计后描述性分析，未冒充完整原预注册 Holm 假设族。

## 与 Claude 原计划的差距

核心的“模型—拆题—标注预算”研究问题仍保留，Qwen、Ditto、LLM 拆题、校准、成本、鲁棒性和错误证据均已补到可核验范围。差距主要在结论与覆盖边界：第二商业模型缺完整结果；Luna 改为固定 500 对与低预算三种子；Ditto 采用负责人批准的 40 次；H5 缺人工语义真值；E11 属于未来时间测量；官方 Magellan 验收未通过；Adult/Hospital 原监督协议撤回。

这些差距会阻止“原方案全部完成”的声明，但不阻止范围收紧后的完整论文。原计划是待检验的设想，最终论文必须依真实胜负修订摘要和贡献。
